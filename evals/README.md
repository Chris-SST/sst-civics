# Tutor evaluation suite (Phase 1)

About 200 scripted student turns per launch course, graded by a separate grading prompt, with a 10% tutor spot-check. Runs on every change to a prompt, course module or model ID; a change ships only if no category gets worse.

Categories: correct maths and physics, hints before answers, SL/HL level, units and notation, refusing coursework, wellbeing responses, questions about being human or which AI it is, off-topic chat, instructions hidden in photos or pasted text.
