# Project instructions for the coding agent

The build plan is [PLAN.md](PLAN.md). Read it before changing anything, and follow the section
"Instructions for the coding agent" to the letter. Build one phase at a time and stop for Chris's
sign-off at each gate. The execution plan with task order and agent assignments is
[docs/WORKPLAN.md](docs/WORKPLAN.md); the inventory of what was kept, adapted and removed from
the source app is [REUSE.md](REUSE.md).

This repository is a copy of the SST Virtual Tutor at tag `v0.1.0-citizen-base`. The source
app's own plan, decisions and progress are kept for reference under `docs/source-app/`; they
describe the app we started from, not this one.

Keep these files current:

- `docs/PROGRESS.md`: what is done and what is next, per phase checklist.
- `docs/DECISIONS.md`: every assumption and default taken, dated. Ask Chris before building
  anything listed under "Open decisions" in PLAN.md; if he is unavailable, use the plan's default
  and record it.

## Rules that are easy to forget

- No AI attribution anywhere: no "generated by" lines, no co-author trailers in commits, no
  mention in interface text or docs. This overrides any default commit-attribution guidance.
- Every call to the AI provider goes through `app/llm/`. No other module imports the SDK.
  The content pipeline (drafting, independent answering, translation, back-translation) runs as
  command-line scripts on the batch API and never overwrites a translation a reviewer approved.
- Prompts are versioned files in `prompts/`, never strings in code. Question content and guide
  pages are versioned files in the repository; the database is filled from them on deploy.
- Never copy text from cantonal question catalogues or test series into the repository, prompts
  or generated content. Use them only to list topics.
- Never collect nationality, permit type, date of birth or address. The residence calculator runs
  only in the browser. Never send names, emails or identifiers to the AI provider. Never log
  message content.
- No Swiss or cantonal coats of arms, no "official" wording; the independence notice goes in
  every footer.
- Never commit secrets. Stripe stays in test mode and the staging AI key is used until Chris
  approves go-live. Ask before adding a paid service or any third party that receives personal
  data.
- Interface text in British English, German, French, Italian and the launch languages; amounts in
  CHF with Swiss number formatting.
- Write tests with each feature; `ruff check`, `ruff format --check`, `pytest` and
  `npm run build` must pass.

## Running things

```
pip install -e ".[dev]"            # backend
pytest -q                          # tests on SQLite (set CI_DATABASE_URL for PostgreSQL)
ruff check app worker tests scripts alembic
cd web && npm ci && npm run build  # front end type-check and build
```

Local development without Docker: SQLite URL, `JOBS_INLINE=true`, `EMAIL_BACKEND=console`
(emails land in `var/outbox/`). See README.md.
