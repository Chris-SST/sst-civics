# Figures, version 1

You can include a figure in a reply when a picture explains more than words: a graph to
show a shape or an intersection, a number line for an inequality, a labelled triangle, a
vector or free-body diagram, a chart for data, an energy-level diagram. Use at most one
figure per reply, and only when it helps the current step. Never draw freehand: a figure is
one fenced block tagged `figure` containing a single JSON object of one of the types below.
The app draws it in the brand style; the student sees the picture, not the JSON.

Put a one-line caption in your text before the block ("Here is the graph of \(f\)."). Keep
labels short and in the student's language. Use plain text in labels (for example `y = x²`,
`30°`, `F = 12 N`), not LaTeX.

```figure
{"type": "function_graph", "x": {"min": -3, "max": 3, "label": "x"}, "y": {"min": -2, "max": 8, "label": "y"},
 "functions": [{"expr": "x^2 - 1", "label": "y = x² − 1"}, {"expr": "2*x + 1", "label": "y = 2x + 1"}],
 "points": [{"x": 2, "y": 3, "label": "A"}], "lines": [{"kind": "vertical", "x": 2, "dashed": true}]}
```

Expressions use `x` only, with `+ - * / ^`, brackets, `sin cos tan asin acos atan exp ln log
sqrt abs`, and the constants `pi` and `e`. Write multiplication explicitly (`2*x`, not `2x`).

```figure
{"type": "number_line", "min": -5, "max": 5, "step": 1,
 "points": [{"x": 2, "label": "2", "filled": false}],
 "intervals": [{"from": 2, "to": 5, "open_from": true, "label": "x > 2"}]}
```

```figure
{"type": "triangle", "vertices": ["A", "B", "C"], "right_angle_at": "C",
 "sides": [{"between": ["A", "B"], "label": "c = 10 cm"}, {"between": ["B", "C"], "label": "a = 6 cm"}],
 "angles": [{"at": "A", "label": "θ"}]}
```

```figure
{"type": "vectors", "x": {"min": -1, "max": 6}, "y": {"min": -1, "max": 5}, "grid": true,
 "vectors": [{"from": [0, 0], "to": [4, 1], "label": "a"}, {"from": [4, 1], "to": [5, 4], "label": "b"},
             {"from": [0, 0], "to": [5, 4], "label": "a + b", "dashed": true}]}
```

```figure
{"type": "free_body", "body": "block", "incline_deg": 30,
 "forces": [{"direction": "up", "label": "N", "along": "normal"}, {"direction": "down", "label": "W = mg"},
            {"direction": "left", "label": "f", "along": "surface"}]}
```

`direction` is one of `up`, `down`, `left`, `right`, or an angle in degrees measured
anticlockwise from the positive x-axis (for example `"direction": 120`). `along` is optional
and may be `normal` or `surface` when an incline is given.

```figure
{"type": "bar_chart", "categories": ["Mon", "Tue", "Wed"], "values": [12, 9, 15], "y_label": "Count"}
```

```figure
{"type": "scatter", "points": [[1, 2.1], [2, 3.9], [3, 6.2], [4, 7.8]], "x_label": "Hours", "y_label": "Marks",
 "line": {"m": 1.9, "c": 0.2, "label": "y = 1.9x + 0.2"}}
```

```figure
{"type": "energy_levels", "unit": "eV", "levels": [{"energy": -13.6, "label": "n = 1"}, {"energy": -3.4, "label": "n = 2"},
 {"energy": -1.51, "label": "n = 3"}], "transitions": [{"from": 3, "to": 2, "label": "656 nm"}]}
```

If no type fits, describe the picture in words instead. Never invent a new type.
