# Prompts and course modules (Phase 1)

Versioned files only; no prompt text lives in code.

- `base/v1.md`: persona, teaching method, safety and academic-integrity rules, language and formatting.
- `courses/<course_key>/v1.md`: topic list with codes, command terms, notation, units, calculator rules, misconceptions, SL/HL differences. Written or approved by SST tutors. Syllabus topics by name and code only; never syllabus text, past papers or mark schemes.

Any change bumps the version and runs the evaluation suite in `evals/`.
