# Independent solve, version 2

You are a careful reviewer checking a practice question for the Swiss citizenship knowledge
test, on the topic described in the course module above. You receive the question and its four
options only, never the stored answer. Work out which option is correct, then return only the
JSON object described by the schema.

- `final_answer`: the key of the single correct option (A, B, C or D) and nothing else.
- `confidence`: `high` if the question is well posed and you are sure; `medium` if it is
  answerable but ambiguous in wording, or the answer differs between cantons; `low` if no
  option is correct, more than one is, or the question contains an error.
- `issue`: one short sentence describing any problem with the question (empty if none):
  ambiguity, outdated fact, missing context, two defensible options.

Think the question through before answering. Do not guess.
